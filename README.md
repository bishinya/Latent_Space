# 潜穹梦影 Latent_Space

试下认真写篇小说，争取不烂尾。<br>
包括且大概不限于<br>中世纪近未来异世界转生悬疑凶杀侦探推理智斗生存玩梗meta严肃搞笑魔法科学战争冒险亲情友情爱情帝王引擎<br>等等等等元素。<br>
~~所以我也不知道这算什么类型的小说<br>元素周期表型kana~~

> [!IMPORTANT]
> **郑重声明<sub>叠甲环节</sub>：<br>
> 本书中构建的所有世界观、国家、组织、科技、社会现象等元素<br>
> 均为完全纯粹的虚构创作，<br>
> 与现实世界中的任何国家、组织、事件、技术皆不存在关联，<br>
> 不构成任何对现实的影射或讽刺。<br>
> 一切设定仅服务于叙事可能性探讨，<br>
> 不表达任何现实政治立场、科学论断，不构成任何投资建议。**

> [!NOTE]
> 这是一本新概念新体验异世界转生多模态交互式小说，  
> 主要灵感来自于  
> **作者本人做的多个时间跨度长达数年的梦。**  
> 嗯真的是睡觉时发生的那个梦境，不是白日梦。  
> 所以这部作品是字面意思的「夢物語」。  
> 作者本人仅对细节部分进行针对性补充。
>   
> 本书添加了**亿些**致敬元素，  
> 涉及出处众多，难以一一列举，  
> 在此感谢各位前辈们带来的无数个精彩故事，  
> 没有这些精神粮食，本书不可能成书。  
> 至于具体是怎么样的致敬，只能说，  
> 如果你觉得有，那应该就是有。
>   
> 本书可能包含一些  
> 对特定**文化概念**或**宗教概念**的**解构**乃至**亵渎，**  
> 若您对相关段落非常介怀甚至达到厌恶的程度，  
> 建议停止阅读，乃至不要再度打开本书。
>   
> 作者本人并未系统学习过写作，  
> 本书所有内容均为赛博猴子打字，  
> 包括且不限于各类笔误、行文不畅、逻辑混乱。  
> 欢迎斧正。
